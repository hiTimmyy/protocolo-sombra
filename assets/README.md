# Convención de sprites (16x16 px, PNG con transparencia)

Carpeta: `assets/sprites/`. Si falta un PNG, la UI dibuja un reemplazo por código.

| Archivo | Descripción |
|---|---|
| `nox_{down,up,left,right}_{0,1,2}.png` | Nox, 4 direcciones x 3 frames (0 = quieta, 1-2 = caminando) |
| `guard_{down,up,left,right}_{0,1,2}.png` | Guardia, mismas reglas |
| `floor.png` | Piso (costo 1) |
| `carpet.png` | Alfombra (costo 2) |
| `wall.png` | Pared |
| `door_open.png`, `door_closed.png`, `door_blocked.png` | Puerta en sus 3 estados |
| `terminal.png` | Terminal a hackear |
| `extraction.png` | Zona de extracción |
| `camera.png` | Cámara de seguridad |
| `bubble_alert.png` | Burbuja "!" (el guardia ve a Nox) |
| `bubble_question.png` | Burbuja "?" (investiga / busca) |

Estética: RPG antiguo tipo GBA. Sin assets con copyright.
